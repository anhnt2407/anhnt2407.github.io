# Tuan Anh Nguyen Website

This repository contains the source for the personal academic website of Tuan Anh Nguyen.

## Stack

- Jekyll
- GitHub Pages
- Custom SCSS and minimal client-side JavaScript

## Structure

- `_pages/` contains the main website sections.
- `research/` contains research overview and detailed research pages.
- `_includes/`, `_layouts/`, and `_sass/` contain the active site templates and styling.
- `assets/` and `images/` contain the published static assets used by the site.

## Deployment

Pushing to the `master` branch triggers the GitHub Pages workflow in `.github/workflows/jekyll-gh-pages.yml`.
